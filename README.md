# recruit-csv-tool

协会招新报名表（问卷导出的 CSV）处理小工具。

零第三方依赖，只需要 **Python 3.8+**，把仓库拉下来就能跑。

## 快速开始

```bash
git clone <仓库地址>
cd recruit-csv-tool
python main.py overview --input data/sample.csv
```

`data/sample.csv` 是一份 23 行的示例报名表，故意塞了各种脏数据（学号带字母、邮箱域名填错、
邮箱和学号对不上、重复报名、整行全空……），可以直接拿来试。

## 需求 2：校验与清洗

```bash
python main.py check -i data/sample.csv -o output/issues.csv
python main.py check --explain        # 打印规则速查表
```

**原始文件只读**：`--input` 指向的 CSV 永远不会被改写，问题清单写到 `-o` 指定的独立路径。

输出（截取）：

```

========================================================
```

### 问题清单 CSV

`output/issues.csv` 一行对应一条有问题的原始记录，列顺序是
`行号, 严重级别, 问题代码, 问题说明, 姓名, 学号, 邮箱, 志愿1, 志愿2, 推荐人`。

把诊断信息放在前面、原始字段放在后面，是为了让人能照着清单直接回问卷后台改。
文件用 `utf-8-sig` 编码，Excel 双击打开不乱码。

### 校验规则

| 代码 | 级别 | 含义 |
| --- | --- | --- |
| E001 | 错误 | 学号为空 |
| E002 | 错误 | 学号不是纯数字（含字母、符号或空格） |
| E003 | 错误 | 姓名为空 |
| E004 | 错误 | 邮箱为空 |
| E005 | 错误 | 邮箱域名不是 `smbu.edu.cn`（含缺 `@` 的情况） |
| E006 | 错误 | 邮箱前缀与学号不一致 |
| E007 | 错误 | 第一志愿为空 |
| E008 | 错误 | 学号重复报名 |
| E009 | 错误 | 整行全空 |
| W101 | 警告 | 学号长度不在 6–12 位 |
| W102 | 警告 | 第二志愿为空（允许） |
| W103 | 警告 | 两个志愿填了同一个部门 |
| W104 | 警告 | 邮箱域名大小写不规范 |

**错误**的行不会进入干净数据；**警告**只是提示，仍然算干净数据。
规则表定义在 `recruit_tool/validate.py` 的 `RULES`，`--explain` 和 README 都从它生成。

## 输入格式

必需列（缺任何一列会直接报错并提示实际表头）：

| 列名 | 说明 |
| --- | --- |
| 姓名 | |
| 学号 | 纯数字 |
| 邮箱 | 应为 `学号@smbu.edu.cn` |
| 志愿1 | 第一志愿 |
| 志愿2 | 第二志愿，可留空 |
| 推荐人 | 可留空 |

CSV 中多出来的列不会被丢弃，会原样保留在数据集里。

## 边界假设

学号到底是 8 位还是 10 位，需求里没说。下面是我替它做的决定，**如果你那边规则不同，
改 `recruit_tool/csvio.py` 顶部的常量即可，所有地方都会跟着变**。

1. **编码**：按 `utf-8-sig → utf-8 → gb18030 → gbk` 顺序自动探测，第一个能完整解码的胜出。
   问卷导出的 CSV 经常带 BOM 或者是 GBK，写死 `utf-8` 会在一半机器上炸掉。

2. **空值的定义（比"空字符串"更宽）**：下列内容都算「没填」——
   - 空字符串、纯空白字符
   - `-` `--` `—` `/`
   - `无` `没有` `暂无` `未填` `未填写`
   - `N/A` `n/a` `NA` `na` `NULL` `null` `None` `none` `nan` `NaN`

   理由：问卷工具经常把未填写渲染成 `-` 或 `无`，只判空串会严重低估缺失率。
   如果你只想认空字符串，把 `csvio.PLACEHOLDER_TOKENS` 改成 `frozenset({""})`。

3. **读入时自动 strip 首尾空白**：`" 2023010120 "` 会被当成 `2023010120` 处理。
   学号前后多一个空格是最常见的手误，没必要为此判人家填错。

4. **行号口径**：所有报错、问题清单里的行号都是 **1 起、不含表头** 的数据行号，
   也就是「在 Excel 里打开 CSV 看到的行号 - 1」。方便人工核对。

5. **学号长度**：需求没说 8 位还是 10 位，所以**不给长度判错**。默认只校验「纯数字」，
   长度落在 6–12 位之外时给一条 `W101` 警告。区间可用 `--min-sid-length` / `--max-sid-length` 改。

6. **重复报名的判定口径**：同一学号出现多次时，**保留首次出现的那一行**，后续行判为 `E008`。
   首次 = CSV 里行号最小的那条（默认按提交时间排序）。学号为空的行不参与重复判定，
   否则几个忘填学号的人会被误判成彼此重复。

7. **邮箱域名大小写不敏感**：`2023010104@SMBU.edu.cn` 视为合法，只给一条 `W104` 提示。
   邮箱前缀（`@` 左边）必须和学号**完全一致**，不做任何容错。

8. **学号非法时跳过邮箱一致性检查**：学号是 `2023010A06` 时，不再提示「应为 2023010A06@smbu.edu.cn」
   ——那句话没有意义。先修学号再说。

9. **第二志愿允许为空**：只有第一志愿是必填的。第二志愿空着只给 `W102` 提示，不影响进入干净数据。

10. **「干净数据」的定义**：一条 error 都没有的行。warning 行照常进入，因为那只是提醒。

11. **原始文件永远只读**：任何一步都不会回写 `--input` 指向的文件，校验过程也不改动内存里的行内容
    （有测试守着：`test_original_rows_are_not_mutated`）。
